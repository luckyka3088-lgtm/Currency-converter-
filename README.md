# 💱 Currency Converter

A modern and responsive **Currency Converter** built using **HTML, CSS, and JavaScript**. It provides real-time exchange rates, supports 160+ currencies, displays country flags, and offers a clean, user-friendly interface.

## ✨ Features

* 🌍 Convert between **160+ currencies**
* 🚀 Live exchange rates using **ExchangeRate-API**
* 🇺🇸 Automatic country flag updates
* 🔄 One-click currency swap
* 💰 Real-time conversion results
* 📈 Displays current exchange rate
* 🕒 Shows the last updated time
* 📱 Fully responsive design
* 🎨 Modern and clean user interface
